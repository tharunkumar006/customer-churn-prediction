Customer Churn Prediction using Machine Learning

Project Overview

This project predicts customer churn using historical customer data and machine learning techniques. Businesses can use this model to identify high-risk customers and take proactive retention measures.

Objectives

- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Machine Learning Model Training
- Churn Prediction
- Feature Importance Analysis

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn
- Jupyter Notebook

Machine Learning Model

Random Forest Classifier

Results

- Accuracy: 89.99%
- Recall: 73.5%

Top Churn Factors

- Churn Score
- Tenure Months
- Monthly Charges
- CLTV
- Contract Type
- Internet Service

Business Impact

The model helps organizations identify customers likely to leave and supports proactive retention strategies.
